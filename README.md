# EIT2-RODA-ILMU
Roda Ilmu ialah permainan papan interaktif yang menggabungkan keseronokan Aeroplane Chess dengan pembelajaran Pendidikan Agama Islam. Pemain bukan sahaja berlumba untuk sampai ke garisan penamat, tetapi juga perlu menjawab soalan PAI yang muncul apabila pesawat mereka mendarat di ruang berwarna tertentu.
